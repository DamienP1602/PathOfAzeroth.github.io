Patch 1.0.1 : Balancing & Bug Fix


Changes

  • Coarse Thread recipe : 3 Strings >>> 2 Strings
  • Increase drop rate of Malachite :
    • copper ore : 5% >>> 10%
    • New : iron ore : 5%
  • Increase drop rate of Tigerseye :
    • copper ore : 5% >>> 10%
    • New : gold ore : 5%
  • Reduces a lot of crafting cost for Blacksmithing, Leatherworking & Tailoring.
  • Desenchantment is now working correctly on all green, blue and purple items.

Fixes

  • Fixed an issue that Murloc, Raptor and Boar wouldn't spawn at all.
  • Fixed an issue that Silver & Thorium smelting wouldn't work.
  • Fixed an issue that after level 5, Players wouldn't gain talent points.
  • Fixed an issue that with Attack power, the donus damage wouldn't count as player damage and so preventing them to have experience or completing quest requirement.
  • Fixed an issue that the Cleave spell was buffed by the talent Improved Heroic Strike and not Improved Cleave
  • Fixed an issue that the Ring of the Dawn's tooltip in the Argent Dawn Reputation UI wasn't showing the name of the object before having the requirement.
  • Fixed an issue that you wouldn't gain reputation with the Argent Dawn Badge equipped.
  • Fixed an issue that the mob Plague Ghoul wasn't tagged as a Dungeon Mob, and wouldn't gain health on hard/heroic difficulties and wouldn't gain reputation points.
  • Fixed an issue that the spell Lifedrain can crash the game.
