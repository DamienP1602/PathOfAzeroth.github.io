Patch 1.0.5 : New Content, Balancing & Bug Fix


New Content

  • New : Players can now select talents from differents specialization to create more unique builds (just with the Warrior class for now)
  • New : Gaining a Level now restaures all Health and Mana to players.
  • New : There's now a sound played when a Player accept a quest or when it's completed.
  • New : When completed quest now gives experience to Players.
  • New : Mobs casting spells now play sound effects when casting.
  • New : The Master Blacksmith can now repair your inventory for free (armor slots + main hand).
  • New : There's a new sound effect and particles when Players learn a new recipe from a job master.

Changes

  • Enriched Mana Biscuit when eaten : 4 (2 food) >>> 8 (4 food)
  • Cooked Boar Meat when eaten : 4 (2 food) >>> 8 (4 food)
  • Murloc Fin Soup when eaten : 4 (2 food) >>> 8 (4 food)
  • Equipped a two handed weapons now makes you drop the off-hand item if you don't have space in your inventory (it was deleted)
  • Spellbooks now show what weapons the class can use to cast spell.

Fixes

  • Fixed an issue that Loksey's Training Stick's effect wouldn't work at all.
  • Fixed an issue that sound effect triggered by hitting a spell on an entity wouldn't be heard by the player.
  • Fixed an issue that the talent Efficiency (hunter) wouldn't work correctly.
  • Fixed an issue that casting the spell Fire Ball in any slots would put the slot 1 on cooldown.
  • Fixed an issue that you could gain reputation after the limit.
  • Fixed an issue that you could stuck yourself in the Ragefire Chasm dungeon.
